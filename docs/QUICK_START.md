# 小说抓取工具 V4.7.5 快速上手

## 1. 下载与登录

从[百度网盘](https://pan.baidu.com/s/1lyuuQwUTJpvkrU5kyGnQow?pwd=dywd)下载软件，提取码：`dywd`；也可在官方 GitHub 仓库对应 Release 有附件时从 Assets 下载。下载 Windows x64 EXE 后，核对发布者提供的 SHA-256 再运行，无需自行安装 Python。完整图文步骤见[用户使用说明书（Word，V4.7.5）](小说抓取工具V4.7.5_用户使用说明书.docx?raw=true)。当前 V4.7.5 EXE 未附数字签名；来源或系统提示存疑时先暂停运行并联系发布者。

已有账号直接登录。首次使用可在登录窗口注册，新用户名使用 1–15 位英文字母或数字，不使用中文、空格或符号；已有账号的兼容规则以软件实际提示为准。设备绑定、余额和导出授权由服务端管理。

## 2. 找到具体小说页面

在搜索栏输入小说名或作者名，选择“全部书源”或指定书源。等待结果后，在内置浏览器打开具体作品页面。部分书源失败时，可选择只重试失败书源；也可在地址栏输入你有权访问和处理的具体网址。

不要在搜索引擎结果页或网站首页直接解析小说目录。遇到网站验证或访问限制时，应按网站允许的方式处理。

## 3. 创建任务并解析目录

在具体小说页面新建任务，使用“网页检测”和“解析目录”。先核对目录章数、前后章节、分卷及顺序，再勾选需要处理的章节。缺少可靠分卷标记时，软件可能保留原网页顺序，仍需人工核对。

## 4. 抓取与复查

开始抓取后查看进度和各章节状态，必要时暂停或继续。异常较多时可降低并发，检查网站及网络后重抓异常章节。

正文为空、仅有标题或夹杂大量无关内容时，打开章节原页并尝试“框选正文”，选择包含多个完整段落的正文区域。换页、刷新或切换任务后应重新框选。

付费跳过、失败或未完成，都不等于已经取得完整正文；不要把“错误为 0”单独作为整本完成的依据。

## 5. 核对后导出 TXT

点击“导出 TXT”，阅读目录完整性、异常内容及未包含章节提示，并检查展示的正文。只有接受实际导出范围后才继续。

导出涉及账户授权与扣费确认，请以界面实际显示为准。取消或存在疑问时先停止，不要反复提交。发生余额或扣费问题，通过软件内显示的管理员渠道联系，不在公开 Issues 上传凭据。

导出后再抽查首尾章节、分卷及异常位置。旧 TXT 不会因升级自动补全，应重新解析并抓取需要修复的章节。

## 6. 更新与反馈

可通过“帮助 → 一键自动更新”检查软件更新，或在官方 Releases 查看版本。更新前妥善保存自己的导出文件，关闭正在进行的任务。

页面识别问题可使用“帮助 → 一键反馈问题”；普通脱敏问题也可在仓库 Issues 提交。不要公开密码、Cookie、机器码、完整日志或无权传播的正文。

## 7. 联网与内容权限

本软件有账号、使用记录、书源规则观测及运行日志上传行为，不是完全离线工具。当前实现会在退出时自动尝试上传日志，并在后续登录时重试待上传文件。

仅处理自有、已获授权或来源明确允许采集和保存的内容。能够访问网页不代表取得批量采集或传播权利；请遵守网站规则、付费限制和著作权要求。
