# 小说抓取工具

Windows 桌面端小说内容采集与 TXT 整理工具，支持多书源搜索、目录解析、批量抓取，以及导出前的完整性和正文质量核对。

**这是软件的公开介绍、下载和问题反馈仓库。软件采用闭源发行方式，本仓库不提供应用程序源码。**

## 下载与运行

在本仓库的 **Releases** 页面查看已公开版本，从对应版本的 **Assets** 下载 Windows EXE。不要把 GitHub 自动生成的 “Source code (zip/tar.gz)” 当作应用程序。

本页对应版本：**V4.7.5**。程序为 Windows x64 版本；其他操作系统及 ARM64 原生版本未提供。下载后运行 EXE，无需自行安装 Python。若 Releases 尚无公开附件，表示该版本尚未对外提供下载。

现有 V4.7.5 EXE 未附数字签名。请核对下载来源和发布页提供的 SHA-256；遇到系统拦截时先停止运行并核实，不要关闭系统保护来绕过提示。

## 主要功能

- **多书源搜索**：按小说名或作者名搜索，汇总各书源结果，支持只重试失败书源。
- **内置网页浏览器**：打开小说页面，进行网页检测、目录解析和正文区域选择。
- **目录与章节管理**：选择需要抓取的章节，核对章节顺序与分卷信息。
- **批量抓取**：查看进度和章节状态，支持暂停、继续及异常章节重抓。
- **正文质量核对**：提示付费跳过、异常内容及未完成章节，辅助检查缺章和分页问题。
- **TXT 导出**：导出前核对正文与未包含章节，避免把“部分完成”误当作完整导出。

## 使用前请了解

软件包含账号登录、服务器书源同步、使用记录及导出授权等联网功能，**并非完全离线软件**。导出涉及账户余额和扣费确认，具体规则以操作时客户端及服务端显示为准；下载程序不代表所有功能永久免费。

运行过程中会生成本地任务、章节、浏览器状态和日志。登录使用时会与服务端交换账号、设备识别码、使用记录等信息；当前实现会在退出时自动尝试上传运行日志，并在后续登录时重试待上传日志。书源规则观测也可能自动上报，不应将本软件理解为“不联网、不记录、不上传数据”的工具。

网站可用性、页面结构、登录状态和访问权限会影响结果。软件不保证所有网站都能识别，也不保证每次导出完整。请在导出前核对目录数量、正文及异常章节；旧 TXT 的缺章、错序或混文不会因升级自动修复。

## 使用边界

仅处理你自有、已获授权，或来源明确允许采集和保存的内容。网页可以访问不等于有权批量采集或再传播；请遵守网站规则、访问限制和著作权要求。不要使用本软件绕过付费、登录、验证码或其他访问控制，也不要上传、分享无权传播的小说正文。
